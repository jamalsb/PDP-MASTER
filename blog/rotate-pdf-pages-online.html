How to Rotate PDF Pages Online: Fix Sideways or Upside-Down Pages

PDF Tips & Guides · November 28, 2026 · 7 minute read

A sideways scan or an upside-down document can make a PDF frustrating to read, print, or share. You can correct the orientation by rotating the pages, then save a new copy. This guide explains the right angle to choose and how to use the Rotate PDF tool in PDF Master.

Open PDF Master, choose Rotate PDF pages, and select the angle that corrects your document.

Choose the correct rotation angle

Before you rotate a PDF, look at the direction in which the page needs to turn. PDF Master offers three choices. The selected angle is applied to every page in the document.

RotationWhen to use it
90° clockwiseUse this when the pages need to turn one quarter-turn to the right.
180°Use this when the pages are upside down and need to be turned halfway around.
270° clockwiseUse this when a quarter-turn to the left is needed. A 270° clockwise turn is the same direction as a 90° counterclockwise turn.

If you are unsure, test the direction on a copy of the document first. A 90° turn in the wrong direction can make a sideways page harder to read, so check the result before sharing it.

How to rotate PDF pages online with PDF Master

The rotation tool works with one PDF at a time. It reads the selected file in your browser and creates a new rotated PDF for you to download.

  1. Open PDF Master. Visit the PDF tools page in your browser.
  2. Choose Rotate PDF pages. Find the rotation tool in the tools area.
  3. Select your PDF. Choose the document from your phone, tablet, or computer. Wait for the file to appear in the selected-file area.
  4. Pick the angle. Choose 90° clockwise, 180°, or 270° clockwise from the Rotation angle option.
  5. Run the tool. Select the Rotate PDF button and allow the browser to finish processing the document.
  6. Save and inspect the result. The rotated file downloads to your device. Open it and check several pages before replacing or sharing your original.
Helpful tip:

Keep the original PDF until you have checked the new file. This gives you a clean way to start again if you chose the wrong direction.

What the Rotate PDF tool changes

PDF Master changes the page rotation setting in the PDF rather than turning each page into a new screenshot. That means the rotation operation does not intentionally rasterize the page or re-encode its text and images. The original page content remains in the document while its viewing orientation changes.

The tool applies the same angle to every page. It is useful when an entire scan or document is consistently sideways or upside down. It is not a page-by-page editor, so it cannot select page 4 and leave all the other pages unchanged.

What if only one page is sideways?

If most pages are already upright and only one page needs turning, do not apply a whole-document rotation. The current PDF Master rotation tool turns every page by the selected amount.

For a mixed-orientation document, use a PDF editor that supports selecting individual pages. Another option is to separate the relevant pages, correct them with a page-specific editor, and carefully combine the parts again. PDF Master can help with the file organization steps: read how to split a PDF online and how to merge PDF files online. Check the page order carefully when rebuilding a document.

File privacy and the original document

The current PDF Master rotation code reads the selected file in the browser and saves a new downloadable PDF. It does not send the PDF document to a PDF Master server for rotation. The website still needs an internet connection to load the page and its PDF library.

The original file is not overwritten by the rotation step. Keep it until you have opened the new copy and confirmed that the pages look right. For confidential documents, also follow the security and sharing rules that apply to your workplace or organization.

Common problems and fixes

The pages turned in the wrong direction

Choose the opposite quarter-turn. If 90° clockwise makes the page worse, try 270° clockwise. Open the downloaded copy to confirm the direction.

Every page rotated, but only one needed correcting

This is expected behavior for the current tool: it applies one angle to all pages. Use a page-specific PDF editor for documents with mixed page orientations.

The downloaded PDF does not appear

Check your browser's Downloads list and any download prompt. If the browser blocked the download, allow downloads for the site and run the tool again.

The file will not process

A damaged, encrypted, or unsupported PDF may not open in the browser library. If you have permission to do so, try a readable copy of the file. Do not remove protection from a document unless you are authorized to make that change.

The file is still too large to email

Rotation does not normally reduce a PDF's size. If you need a smaller attachment, see our guide to compressing PDF files online. Review the output carefully because compression can affect selectable text and other document features.

Frequently asked questions

How do I rotate PDF pages online?

Open a browser-based PDF rotation tool, select the document, choose the required angle, and save the new file. In PDF Master, choose Rotate PDF pages and select 90°, 180°, or 270° clockwise.

Can I rotate a PDF by 90 degrees?

Yes. Choose 90° clockwise to turn every page one quarter-turn to the right. Choose 270° clockwise for a quarter-turn to the left.

How do I turn an upside-down PDF upright?

Choose 180° if all pages are upside down. If the pages are sideways instead, use 90° or 270° depending on which direction makes them upright.

Can I rotate only one page of a PDF in PDF Master?

Not with the current Rotate PDF tool. It applies the selected angle to every page in the file. Use a PDF editor with individual-page rotation when only one or a few pages need correcting.

Will rotating a PDF reduce its quality?

The PDF Master rotation function updates page rotation settings instead of converting the pages into images. It does not intentionally reduce image resolution or turn selectable text into pixels. Always inspect the saved document before using it.

Can I rotate a PDF on my phone?

You can open PDF Master in a mobile browser, select a PDF from your device, choose a rotation angle, and download the result. The available file picker and download behavior can vary by browser and device.

Final thoughts

Rotating a PDF is a simple fix when every page needs the same orientation correction. Choose the angle carefully, keep your original file, and inspect the downloaded copy. If the document contains a mixture of upright and sideways pages, use a tool that supports page-by-page rotation instead of applying one angle to the whole file.
