How to Split a PDF Online: Extract Selected Pages with PDF Master

Sometimes you do not need to send or keep an entire PDF. You may only need a few pages from a report, a section of a handbook, or selected pages from a form. This guide explains how to split a PDF online with PDF Master, enter page ranges correctly, and check the new file before sharing it.

What does it mean to split a PDF?

The phrase split a PDF can describe more than one job. Sometimes it means extracting a few chosen pages into a new document. In other cases, it means dividing a long PDF into several separate files, such as one file for each chapter or one file for every page.

PDF Master's Split PDF tool is designed for the first job: it takes one PDF and creates one new PDF containing the page numbers or ranges you select. It is useful when you want to share a focused section without sending the full document.

Important: One split operation creates one PDF containing all selected pages. It does not automatically create a separate file for every page or for every range you enter. The exact options are explained below so you can choose the right workflow.

When should you extract selected pages?

Extracting pages can make a document easier to send, review, or organise. For example:

  • Reports: keep the summary and findings pages instead of sharing the full report.
  • Study notes: extract a chapter or a short page range from a longer set of notes.
  • Forms: create a copy containing only the pages a recipient needs to review.
  • Invoices and records: collect specific pages from a combined PDF for a separate filing task.
  • Manuals: share the instructions for one product or section without attaching the entire manual.

Check that the extracted pages still have enough context to make sense on their own. If a page refers to a table, definition, or instruction elsewhere in the original document, include that supporting page too.

How to split a PDF online with PDF Master

  1. Open PDF Master. Go to the PDF tools on the homepage and select Split PDF pages.
  2. Choose one PDF file. Select the document from your device. The Split tool accepts one PDF at a time.
  3. Enter the pages you need. In the page-range field, type individual page numbers, ranges, or a combination separated by commas.
  4. Check your selection. Confirm that every number is within the document's page count and that each range starts with a lower number than it ends with.
  5. Run the split. Click Split PDF. PDF Master creates a new PDF containing the selected pages.
  6. Open the downloaded file. The output is named pdf-master-split.pdf. Check the page count, order, and content before sending or storing it.

The original file stays as it was. The tool reads the selected file and generates a separate output, so you can keep the source PDF as a backup.

How to enter page numbers and ranges

Use a comma to separate individual pages or ranges, and a hyphen to describe a continuous range. The first and last page in a range are both included.

What you enterPages includedWhen to use it
4Page 4Extract one page.
2-5Pages 2, 3, 4, and 5Extract one continuous section.
1-3, 7, 10-12Pages 1, 2, 3, 7, 10, 11, and 12Combine several separate selections into one new PDF.

For example, if you enter 7, 1-2, the output is arranged in the document's original page order: pages 1, 2, and then 7. The tool sorts the selected page numbers into ascending order. If the same page is entered more than once, it is included once.

Use the page position shown by your PDF reader, not only the printed page number at the bottom of a page. A document may have a cover and contents pages before its printed page 1, so the PDF viewer's page 5 might be labelled page 3 inside the document.

Page numbers must be between 1 and the total number of pages. A range such as 5-2, a page number of 0, or a number beyond the end of the document will be rejected. If the field shows an error, check the digits, comma separators, and hyphen.

Privacy and local processing

PDF Master processes the selected document in your browser. The application reads the file from your device, creates the new PDF in the browser, and does not upload the document contents to a PDF Master application server. There is no account or server-side document storage in this project.

The page loads its PDF-processing libraries from public content-delivery networks, so an internet connection is needed to load the tool. Once the page and libraries are available, the selected PDF is handled in the browser. For work documents, follow your organisation's document-handling rules and keep the original file in a safe place.

Common problems and fixes

The page range is rejected

Check that page numbering starts at 1, each number exists in the PDF, and every range runs from a smaller number to a larger one. Use commas between selections, for example 1-3, 5, 8-10.

The output contains a different page order than I typed

PDF Master places selected pages in their original document order. If you type 8, 2, 4, the new PDF contains pages 2, 4, and 8 in that order. This keeps the extracted document aligned with the source PDF.

The page numbers do not match the printed numbers

Use the page counter in your PDF reader. Cover pages, contents pages, and front matter can make the PDF's page position different from the number printed on the page itself.

The PDF will not open or the split fails

Confirm that the source is a valid PDF and can be opened in a regular PDF reader. A damaged or password-protected document may not load. PDF Master does not unlock protected files; use a copy you are authorised to access, or ask the document owner for an accessible version.

The download does not appear

Check your browser's downloads list and make sure downloads are allowed for the site. On a phone, also check the browser's Downloads folder or the device's Files app.

The document is large or the browser becomes slow

PDF processing uses your device's available memory. Close other heavy tabs, try a modern browser, or use a computer for a particularly large document. There is no need to upload the original to a separate service just to try the extraction again.

Frequently asked questions

Can I split a PDF online by selecting specific pages?

Yes. In PDF Master, select one PDF and enter individual page numbers or ranges, such as 2, 5-7, 10. The selected pages are saved together in one new PDF.

Can I extract several non-consecutive pages?

Yes. Separate the page numbers and ranges with commas. For example, 1, 4, 8-10 selects pages 1, 4, 8, 9, and 10.

Will the extracted pages follow the order I typed?

No. They are placed in ascending order based on their positions in the original PDF. This keeps the original document sequence.

Does splitting change my original PDF?

No. PDF Master creates a separate output file. Your source PDF is not overwritten.

Can PDF Master save every page as a separate PDF?

Not in one operation with the current Split tool. It creates one PDF containing all the pages you select. To make separate files for different page ranges, run and save each range separately.

Are my files uploaded to a server?

The selected PDF is processed in your browser and is not uploaded to a PDF Master application server. The site does load its PDF libraries from public CDNs, so an internet connection is needed to open the tool.

Can I use the Split tool on a phone?

You can open PDF Master in a modern mobile browser and choose a PDF from your device. Very large files may work more smoothly on a computer because browser memory varies between devices.

Will digital signatures, forms, and bookmarks work exactly the same?

Do not assume that interactive features will behave identically in an extracted copy. Review forms, annotations, links, bookmarks, and signatures in the output. If a digital signature must remain verifiable, keep the original signed PDF and confirm the recipient's requirements before sharing an extracted copy.

Final thoughts

When you only need a few pages, extracting them can make a PDF easier to share and organise. With PDF Master, select one document, enter the page numbers or ranges, and save the new PDF. Remember that the current tool combines all selected pages into one output file, so check the result before sending it.
